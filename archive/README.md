# 归档代码说明

本目录包含已归档的代码，这些代码在当前架构中不再使用，但保留以备将来参考或恢复。

## 归档内容

### agent_router/
队列路由器模块，用于Redis队列架构的消息路由。当前系统使用直接调用模式（server.py + business_services），不再需要队列路由。

**归档原因**：系统已简化为直接调用模式，不再使用Redis队列架构。

**保留原因**：如果将来需要恢复异步队列处理能力，可以参考此代码。

### agent_service/
查询和总结服务模块，提供查询和总结功能。这些功能已被集成到各业务模块中。

**归档原因**：查询和总结功能已直接集成到 business/ 下的各业务模块中，不再需要独立的服务模块。

**保留原因**：如果将来需要统一的服务层，可以参考此代码。

### main.py
多进程启动器，用于启动多个Agent进程（agent_router, agent_structurizer, agent_storage等）。

**归档原因**：当前系统使用直接调用模式，不再需要多进程架构。

**保留原因**：如果将来需要恢复多进程架构，可以参考此代码。

## 注意事项

- 这些代码可能包含过时的导入路径
- 如果需要恢复使用，需要更新导入路径以适配新的项目结构
- 建议在恢复前先查看新的架构文档
